GÓI WEB CÀI ĐẶT CHIẾN BINH VEGETA CHO VPS

CÀI LÊN WEBSITE
1. Giải nén ChienBinhVegeta-VPS.zip trên máy tính.
2. Chép thư mục ios bên trong gói vào document root của website trên VPS.
   Nếu website đã có thư mục ios, hãy sao lưu trước khi thay thế.
3. Bảo đảm website có HTTPS hợp lệ, rồi mở:
   https://chienbinhvegetablue.com/ios/
4. Trên iPhone hoặc iPad, mở trang bằng Safari và chạm “Cài đặt ngay”.

CÁCH HOẠT ĐỘNG
Trang cài đặt được VPS của bạn phục vụ. Nút cài đặt lấy manifest và IPA từ GitHub Pages:
https://anhhphuong06.github.io/Chienbinhvegeta/ios/manifest.xml
https://anhhphuong06.github.io/Chienbinhvegeta/ios/ChienBinhVegeta_1.0_1792645622.ipa
Vì vậy cần giữ GitHub Pages bật và không đổi/xóa các file cài đặt ở đó.
DNS tên miền vẫn trỏ về VPS. Không cần chuyển website sang GitHub Pages.

CẤU HÌNH SERVER
Đây là website tĩnh; không cần Node.js, PHP hoặc database.
Apache: file .htaccess trong thư mục ios khai báo MIME cho XML, plist và IPA.
Nginx: nếu cần, thêm nội dung nginx-ios.conf vào khối server {} hiện tại.
Cấu hình Nginx dùng document root đang có; kiểm tra bằng nginx -t trước khi reload.
Web server cần quyền đọc thư mục và file (thường thư mục 755, file 644).
Nếu Cloudflare đang bật thử thách trình duyệt cho /ios/*, hãy cho phép đường dẫn này
để người dùng mở được trang cài đặt.
